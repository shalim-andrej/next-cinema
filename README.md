# 🎬 Next.js Кинотека

Современное веб-приложение для поиска фильмов и управления списком избранного. Проект создан в рамках портфолио для демонстрации навыков работы с современным стеком фронтенд-разработки.

## 🚀 Стек технологий
- **Фреймворк:** Next.js 16+ (App Router, Turbopack)
- **UI-библиотека:** React 19 (Server Components, `useOptimistic`, `useTransition`)
- **Язык:** TypeScript 5
- **Стилизация:** Tailwind CSS v4 (CSS Variables, `@theme`)
- **API:** Кинопоиск API (unofficial)

## ✨ Ключевые особенности
- **SSR и Server Components:** Данные запрашиваются на сервере для максимальной скорости загрузки.
- **Поиск с Debounce:** Состояние поиска синхронизировано с URL (`?q=...`), что позволяет делиться ссылками на результаты поиска.
- **Пагинация:** Переключение страниц через URL (`?page=...`) с сохранением состояния истории браузера.
- **Server Actions:** Добавление и удаление фильмов из избранного без создания дополнительных API-роутов.
- **Оптимистичный UI (React 19):** Мгновенная реакция интерфейса на действия пользователя до ответа сервера.
- **SEO-оптимизация:** Динамические мета-теги (`generateMetadata`) для каждой страницы фильма.
- **Управление состоянием:** Избранное сохраняется в cookies (на сервере) и доступно после перезагрузки страницы.
- **Адаптивность:** Интерфейс идеально смотрится на мобильных устройствах и десктопах.
- **Кастомные экраны:** Обработка ошибок (`error.tsx`), скелетоны загрузки (`loading.tsx`) и страница 404 (`not-found.tsx`).

## 🛠️ Установка и запуск локально
1. Склонируйте репозиторий.
2. Установите зависимости: `npm install`.
3. Создайте файл `.env.local` в корне и добавьте ключ API Кинопоиска:
4. Запустите сервер разработки: `npm run dev`.
5. Откройте `http://localhost:3000`.

Проект оптимизирован для деплоя на платформе Vercel. Не забудьте добавить переменную окружения `KINOPOISK_API_KEY` в настройках проекта на Vercel.
